# ShopSmart Business Questions

This folder documents the business questions that guide the SQL analysis.

## Practised so far

- Which products are priced above ₹1,000?
- Which Fashion products are priced above ₹1,000?
- Which products belong to selected categories (Fashion, Beauty, Home)?
- Which users are located in Delhi or Bengaluru?
- Which distinct cities appear in the user dataset?

These are learning exercises. They are not yet presented as validated business findings.

## Pending analysis

1. Which acquisition channels bring in the most users, and how do outcomes compare by channel?
2. Which product categories generate the most revenue?
3. How many customers are repeat purchasers?
4. What are the average order value and cancellation rate?
5. How does product performance vary over time?

## Explicitly excluded

**Purchase funnel analysis is excluded from this project’s current scope.** The event data was generated independently and does not reliably represent sequential steps in an individual customer's journey. Funnel conversion and drop-off claims would therefore be unreliable with the current dataset.

As each question is analysed, add its metric definition, relevant assumptions, and a link to the matching SQL and results files.
