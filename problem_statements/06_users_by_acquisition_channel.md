# PS-06: Users by Acquisition Channel

## Business question
How many users were acquired through each acquisition channel, and which channels contributed the most users?

## Objective
Summarize the user base by acquisition channel to understand the volume of users attributed to each channel.

## SQL concepts
- `GROUP BY`
- `COUNT(*)`
- `ORDER BY ... DESC`

## Interpretation note
This analysis measures user volume only. It does not establish acquisition efficiency, cost-effectiveness, conversion, or user value. Those questions require additional data, such as channel spend or downstream user behaviour.
