# Query Results and Business Insights

Record the actual output and interpretation of each completed SQL analysis here. Do not invent results or copy example numbers that have not been returned by PostgreSQL.

For each question, document:

1. **Business question**
2. **Metric definition and assumptions**
3. **Result** — a small table or screenshot/export of the real query output
4. **Interpretation** — what the result does and does not tell us
5. **Business implication / next question**
6. **Limitations**

Use matching filenames where possible, for example `01_basic_product_queries.md` or `04_category_revenue_analysis.md`. Add a result only after running and validating the corresponding query.

All ShopSmart data is synthetic, so insights apply only to this generated dataset and must not be presented as real business performance.
