# ecommerce-product-analytics-sql-powerbi
For, beginners to integrate SQL, Power BI for dashboards. 

ShopSmart — Product Analytics Using SQL and Power BI		

Business Scenario
A fictional Indian B2C shopping app wants to understand purchase conversion, category performance, acquisition channels, and repeat purchases.		

users (user_id, signup_date, city, acquisition_channel)
products (product_id, category, price)
events (event_id, user_id, event_name, event_date, product_id)
orders (order_id, user_id, order_date, amount, status)
